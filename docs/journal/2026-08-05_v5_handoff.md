- 从 SFT scorer 初始化

- driving_scale=3.0
- safety_beta=0.03（注：实际启动时漏传了 --safety-beta 参数，当前实际为 0.0）

- safety_beta=0.0 不是致命问题，核心改动是 True PDMS reward + 去掉 efficiency_bonus
- 当前 step 3 运行正常，kr=0.55 稳定，R 在合理范围
- 重启浪费 ~30min 加载时间
- 如果需要，epoch 2 可以从 ckpt resume 加上 safety_beta
